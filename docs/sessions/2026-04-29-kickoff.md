## Operational commands cheat sheet

```bash
# Deploy
~/.fly/bin/fly deploy --local-only --strategy rolling

# Logs
~/.fly/bin/fly logs -a evidenceengine --no-tail

# Push pipeline (lesson 58)
git repack -ad   # if loose objects > 500
git push origin main

# Run bio test
BASE=https://evidenceengine.fly.dev
RESP=$(curl -sS -m 180 -X POST "$BASE/api/packets/" \
  -F "report=@/path/to/bio-paper.pdf" \
  -F "sources=@/path/to/cited-paper.pdf")
PID=$(echo "$RESP" | python3 -c "import sys,json;print(json.load(sys.stdin)['id'])")
RUN=$(curl -sS -m 60 -X POST "$BASE/api/packets/$PID/run" | python3 -c "import sys,json;print(json.load(sys.stdin)['run_version_id'])")
echo "Dashboard: $BASE/dashboard/$PID/$RUN"
```

## Honest concerns to raise

1. **Speed**: 25 min cold-cache is unusable for production users. P0 P0 P0.
2. **Insufficient_support is 56% of verdicts on average** — most claims show insufficient. UX gap: user has to manually decide what that means. Could surface "evidence found but didn't entail/contradict" as more actionable copy.
3. **Citation-first sampling biases against novel claims**: 25-cap fills with cited claims first; novel/uncited contributions of the user's own paper get dropped. Architectural trade-off worth revisiting after speed work lands.
4. **NLI threshold band calibrated on SciFact only** (clinical trial claims): bio papers from non-RCT domains (case reports, observational studies, basic science) may show different distributions. Worth a SciFact-benchmark re-run to update CLAUDE.md numbers.
