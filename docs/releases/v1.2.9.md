# v1.2.9 Release Notes (in progress)

## Phase 1: Provider Migration (2026-04-21)

Replaced the 98%-failing OpenRouter `:free` fallback chain with Google AI
Studio Gemini 2.0 Flash (primary) + Groq Llama 3.3 70B (fallback).

**Why**: Live probing on 2026-04-21 showed every OpenRouter free model in the
default chain either 429'd or 404'd within the first retry round. Downstream
phases (SciFact evaluation, NLI tiebreaker) cannot land on an unreliable
provider.

**How**: Both Gemini and Groq expose OpenAI-compatible endpoints, so
`sync_call_with_fallback` needed only a tiny per-model-id dispatch layer
(routes `gemini-*` → Google AI Studio, `llama-*`/`mixtral-*` → Groq, anything
else → caller-provided `base_url`). No caller code changed.

**Behavioral impact**: None intended. Existing unit tests pass with only
model-name constants updated. A new live test (`pytest -m live
tests/test_live_gemini.py`) proves the round-trip works.

**Phase 1 commits**:
- `7ddbdf2` — `feat(phase-01): extend Settings with Gemini/Groq provider fields`
- `5934077` — `feat(phase-01): rewrite .env.example with Gemini-first config + migration note`
- `fe5b55e` — `feat(phase-01): per-model provider dispatch in fallback.py`
- Plus SUMMARY commits and the final CHANGELOG + release-notes commit.

**Migration**: see `CHANGELOG.md` → `[v1.2.9]` → Migration section.

**Rollback**: one `git revert` of the Phase 1 commits restores OpenRouter
defaults — no data migration needed.
