## What shipped

### Editorial UI redesign
- Tailwind v4 design system with a full token set (`--color-ink-*`, `--color-paper-*`, `--color-accent-*`, `--color-verdict-*`, `--font-serif`, `--font-sans`, `--font-mono`).
- 10 reusable Jinja2 component macros: `_badge`, `_button`, `_card`, `_collapsible`, `_confidence`, `_empty_state`, `_evidence_span`, `_kbd`, `_pill_distribution`, `_provenance_step`, `_topbar`.
- Three-zone reviewer UI rebuilt end-to-end: topbar + queue panel + claim detail panel.

### Quality-of-life / UX
- Keyboard shortcuts: `A` approve, `R` reject, `F` mark insufficient, `J`/`K` navigate, `?` open help overlay, `Esc` dismiss.
- HTMX error toast on `htmx:responseError` — dismissed after 4 s.
- Reviewed rows dim to 55% opacity (visual progress tracking).

### Error surfaces
- HTML 404 and 500 pages with `Accept`-header content negotiation: browser GETs return styled HTML extending `base.html`; API calls still receive JSON.
- Unreviewable-run guard: hides review buttons and shows a banner when a run has no verdicts yet.

### Font self-hosting (Phase 4)
- Source Serif 4, Inter, and JetBrains Mono are now served from `/static/fonts/` (WOFF2, latin + latin-ext subsets).
- Zero third-party CDN requests for typography. `fonts.googleapis.com` references removed from all templates.

### Accessibility (Phase 5)
- Collapsible panels: `aria-controls`, `role="region"`, `aria-labelledby` wired to panel IDs.
- Queue claim rows: `role="button"`, `tabindex="0"`, `aria-label`, keyboard trigger on Enter/Space.
- Filter selects: screen-reader-only `<label>` elements for each filter control.
- Review button area: stable `aria-live="polite"` region so verdict state changes are announced.
- Skip link to `#detail-panel` as first body element.
- Chevron decorations marked `aria-hidden="true"`.

---

## Migration notes

No database schema changes. No configuration changes. This is a pure frontend / template layer change.

To update a running instance: `git pull && npm run build:css && restart uvicorn`.

---

## Known limitations

- Playwright axe-core browser audit requires a live server with seed data; run manually with `scripts/take_screenshots.js` extended with `axe-playwright`.
- `design-system` route is only accessible when `settings.debug=True`.
- Auth is deferred to v1.3; the app is intended to run behind a reviewer VPN.
